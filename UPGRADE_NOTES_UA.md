# Техно-Дім Premium — оновлення

## Нові можливості
- `/compare` — порівняння до трьох товарів (сесія браузера).
- `/account` — особистий кабінет, історія покупок, обране.
- `/admin/stats` — оборот, середній чек, топ продажів, помісячний графік.
- Checkout — візуальний макет картки **без збору реквізитів**.

## Оплата — важливо
Це навчальний магазин. Форма **не приймає реальні платежі** і не збирає номер картки/CVV. Для продакшн-оплати потрібен провайдер (LiqPay, WayForPay, Stripe тощо) з hosted checkout/tokenization, перевіркою webhook та статусом платежу. Не додавайте поля card_number/CVV до Rails-моделей чи логів.

## Запуск
1. Розпакуйте архів у нову папку, не перезаписуючи стару.
2. `bundle install`
3. `bundle exec rails db:migrate`
4. `bundle exec rails server -p 3001`
5. Відкрийте `http://localhost:3001`.

## Перевірка
`bundle exec rails test` — вимагає локально встановлених Ruby/gems. Перевірте вручну каталог, порівняння, вхід, кабінет, оформлення, адмін-статистику. Не видаляйте стару версію до перевірки.
