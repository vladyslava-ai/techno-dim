# Техно-Дім · оновлена версія

## Що змінилося
- Преміальний темний адаптивний дизайн з теплими помаранчевими акцентами, оновлені картки, форми, каталог і головна сторінка.
- Bootstrap 5.3.3 CSS підключено через CDN; власні стилі завантажуються після нього. Для завантаження Bootstrap потрібен інтернет. Без нього власні стилі продовжують працювати.
- Виправлено часовий пояс `Europe/Kyiv` і зайві маршрути адміністратора.
- Безпечніше оформлення замовлень: транзакція, блокування рядків товарів, перевірка залишків, атомарне списання та ціни на момент покупки.
- Після успішного оформлення ставиться в чергу `OrderConfirmationJob`, який **тільки пише подію в журнал** (не надсилає реального листа).
- Додано тести правил замовлень та фонового завдання; збережено наявні тести.
- Збережено оригінальну базу даних, картинки, товари, користувачів та замовлення.

## Як запустити у WSL Ubuntu
1. Розпакувати архів у нову папку (не поверх працюючого сайту).
2. `cd shop`
3. `bundle install` (потрібні Ruby 3.2.3 та Bundler).
4. `bundle exec rails db:migrate`
5. `bundle exec rails server -p 3001`
6. Відкрити http://localhost:3001

Тести: `RAILS_ENV=test bundle exec rails db:prepare` та `bundle exec rails test`.

**Увага:** `db:reset` і `db:seed` не запускати, якщо хочете зберегти дані. `storage/development.sqlite3` включено в архів. Не публікуйте архів з реальною базою користувачів у відкритому репозиторії.
